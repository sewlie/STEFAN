FILES

OPEN IN VS CODE
1. Extract the ZIP file.
2. Open VS Code.
3. Choose File > Open Folder and select the extracted kidney-donor-basic folder.
4. Open index.html.
5. For a local preview, install the Live Server extension, right-click index.html, and choose Open with Live Server.

CUSTOMIZE
- In index.html, replace Alex with your friend's name.
- Replace the sample story with details your friend has approved.
- Confirm the transplant program's official contact details before publishing.
- The illustration is made with CSS, so no personal photos are required.

IMPORTANT
This is a draft template. The sample story is fictional placeholder copy. Do not publish it as a factual account. Have the transplant team verify donation information and contact instructions before launch. The page does not collect donor medical information.
